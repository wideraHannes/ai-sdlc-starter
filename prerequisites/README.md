# prerequisites

<img src="../assets/SDLC_loop.png" alt="Der DevOps-Loop mit den KI-Berührungspunkten je Phase" width="520">

Hintergrundmaterial zum Nachlesen. Nichts davon wird im Prozess gebraucht — es
erklärt, warum der Prozess so aussieht, wie er aussieht.

- [`sdlc_refresher.md`](sdlc_refresher.md) — der DevOps-Loop von Plan bis
  Monitor, die KI-Berührungspunkte je Phase, die Begriffe und die Übungen. Wer
  im Workshop war, liest das als Erinnerungsstütze; wer neu dazukommt, bekommt
  hier den kompletten Kontext.
- `ai_assisted_coding_slides.pdf` — die Folien, auf denen der Refresher beruht.

Die Prompts aus dem Workshop liegen nicht hier, sondern einsatzbereit in
[`../sdlc/standards/prompts/`](../sdlc/standards/prompts/README.md).
